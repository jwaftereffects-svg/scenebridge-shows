# SceneBridge Shows

The shared list of custom shows that every copy of SceneBridge loads.
Edit `shows.json` (or double-click **Update Shows** on your desktop) and the apps pick it up within a few minutes.

Each pack can have a `scenepackId`: the number from `scenepacks.com/download/<number>`.
Leave it `null` to let the app find the best 1080p+ match on ScenePacks automatically.
